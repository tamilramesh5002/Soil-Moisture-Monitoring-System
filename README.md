🌱 Soil Moisture Monitoring and Automatic Irrigation System using LPC2129

 📌 Project Overview
The Soil Moisture Monitoring and Automatic Irrigation System is an embedded systems project developed using the LPC2129 ARM7 microcontroller.

The system monitors soil moisture levels using a soil moisture sensor and displays the moisture status on an LCD display. Based on the detected moisture level, the microcontroller controls a water pump through a motor driver. A GSM module is used to send SMS notifications about the irrigation status.

 🎯 Project Objectives
- Monitor soil moisture levels continuously.
- Display soil moisture status on an LCD.
- Automatically control the water pump.
- Send irrigation status notifications using GSM.
- Reduce unnecessary water consumption.

 ⚙️ Hardware Components
- LPC2129 ARM7 Microcontroller
- Soil Moisture Sensor
- 16×2 LCD Display
- GSM Module
- Motor Driver
- DC Water Pump

 🔄 Working Principle
1. The soil moisture sensor detects the moisture level in the soil.
2. The LPC2129 microcontroller processes the sensor input.
3. The LCD displays the soil moisture status.
4. When the soil becomes dry, the microcontroller sends a control signal to the motor driver.
5. The motor driver activates the water pump to supply water.
6. Once the required moisture level is reached, the pump is switched OFF.
7. The GSM module sends SMS notifications about the irrigation operation.
